# 🌿 Tatra Flora Quiz

Interaktywny quiz do nauki roślin Tatrzańskiego Parku Narodowego.

## ✨ Funkcjonalności

- Quiz z 4 opcjami odpowiedzi
- Losowanie roślin i zdjęć
- Natychmiastowe sprawdzanie odpowiedzi
- Przewodnik ze wszystkimi gatunkami i opisami
- Galeria zdjęć dla każdego gatunku
- Responsywny design na telefon i komputer

## 🚀 Uruchomienie

### Lokalnie
Otwórz `index.html` w przeglądarce.

### GitHub Pages
Settings → Pages → branch `main` → folder `/`.

## 📝 Dodawanie nowych roślin

1. Dodaj wpis do `plants.json`.
2. Dodaj cztery zdjęcia do pola `images`.
3. Opcjonalnie dodaj powiązane gatunki do `relatedPlantsMap` w `script.js`.
